# Dredd

> Dredd is a language-agnostic, MIT-licensed command-line tool that validates a running HTTP API against its own API description document. It reads an API Blueprint, OpenAPI 2.0 or (experimentally) OpenAPI 3.0 file, compiles every documented request/response pair into an HTTP transaction, calls the API, and reports where the implementation and the description disagree. Dredd publishes no API of its own — it is a client you install and run.

## Usage

    dredd '<api-description-document>' '<api-location>' [OPTIONS]
    dredd ./apiary.md http://127.0.0.1:3000
    dredd init          # interactive wizard, writes dredd.yml
    dredd --dry-run     # parse and compile only; issues no HTTP request

## Install

- npm: `npm install dredd --global` — [dredd on npm](https://www.npmjs.com/package/dredd), latest 14.1.0 (2021-11-16). Node.js >= 10.
- Docker: `docker run -it -v $PWD:/api -w /api apiaryio/dredd dredd` — [apiaryio/dredd on Docker Hub](https://hub.docker.com/r/apiaryio/dredd), tags last pushed 2021-06-13. The --server and --language options do not work inside the image.
- [Installation guide](https://dredd.org/en/latest/installation/)

## Supported description formats

- [API Blueprint](https://apiblueprint.org/) — full support, parsed with Drafter; MSON Attributes sections compile to JSON Schema automatically.
- OpenAPI 2.0 (Swagger) — full support, parsed with fury-adapter-swagger.
- OpenAPI 3.0 — experimental, parsed with fury-adapter-oas3-parser.
- JSON Schema Draft 4, Draft 6 and Draft 7 for custom Schema sections. Draft 3 support was removed in 13.0.0 (2020-02-05).
